# ProfilePilot 浏览器任务产品

## 已确认范围

在现有 ProfilePilot 中实现面向运营和个人用户的浏览器 Agent。使用 Claude Agent SDK，独立进程运行；不引入 DL-Code，不叠加 Browser Use 的 Agent 循环。Browser Use 仅作为页面观察、动作失效、结果记录的设计参考。保留既有浏览器管理功能和 Gateway 的一 Profile 一 Session、人工接管边界。

## 产品行为约定

- 页面内容不改变用户任务、授权范围或资料访问边界。缺少的个人信息不能编造。
- 当前任务资料优先于默认资料；网页信息不能自动覆盖资料中心；临时回答不自动长期保存。
- 执行状态包括排队、执行、等待用户、暂停、完成、部分完成、失败、取消。外部操作另有“结果未确认”状态。
- 同一 Profile 仅一个任务执行，等待接管仍保留任务占用；不同 Profile 遵守并发限制。
- 观察结果带版本；导航、切页、关键 DOM 变化、接管使旧引用失效。交还必须重新观察。
- 暂停/取消不撤销已经发生的外部操作。执行请求先落盘，返回后落盘结果；崩溃期间的提交先核查再重试。
- 提交确认包含具体目标、内容及页面依据。关键事实变化使确认失效。已明确授权的范围内不重复确认。
- 支付交给用户在网站完成。登录、验证码和不支持的控件支持人工接管。
- 历史恢复不等于网站恢复。结果依据是回执、记录页、页面证据，不能只根据模型说“完成”。
- 调度仅在本机应用可用时执行；错过计划不假装完成，不盲目补交外部操作。
- 默认本地存储；模型会收到完成任务所需内容。API 密钥使用系统保护存储；导出诊断需要脱敏。

## 实现边界

任务管理负责持久化、队列、授权、资料、结果及调度。独立 SDK worker 只拥有通过 IPC 暴露的产品工具，不加载用户机器的任意 MCP、项目指令或 shell 工具。浏览器适配器调用现有受控 wrapper/Gateway，不直连 Chrome。界面与任务运行生命周期分离。

## 验证约束

优先在可控本地网站验证填写、提交、批量、动态页面、断线和恢复，不以真实投递/购物制造外部副作用。真实模型测试需要有效的用户配置；没有凭据时如实记录未验证，不能用模拟通过代替。性能对照必须记录同条件样本、运行模式、成功率、耗时和介入次数。


## 当前模型配置

本机已使用系统安全存储保存用户提供的凭据，源码与报告不包含密钥。配置为 `https://api.moonshot.cn/anthropic`、`kimi-k3`。兼容服务支持自动选择或显式选择 API Key / Bearer 鉴权；同一 worker 内将后台模型别名映射到所选模型，不读取用户全局 Claude 设置。

2026-09-19 已验证 Kimi 官方模型列表鉴权、开发/Windows 打包运行时连接及真实浏览器任务。参考 [Kimi 官方 Claude Code 接入文档](https://platform.kimi.com/docs/guide/claude-code-kimi) 与 [模型列表](https://platform.kimi.com/docs/models)。SDK 的费用是估算值，兼容服务的账单以服务商为准。

## 已确认的实现限制

- 页面原文校验可以拒绝凭空生成的回执，不能证明模型已正确理解全部业务条件。
- 外部动作识别同时依赖工具 effect 和按钮语义启发式；复杂网站仍需要实际测试。支付交还用户处理。
- 暂停、取消、超时与断线不能撤销已经到达网站的请求，也不提供跨网站的严格 exactly-once 保证。
- Windows 后台 Chrome 在未绘制页面时可能丢失原生点击。浏览器适配器会先滚动并捕获一个临时渲染帧，再发送一次点击；临时帧立即删除，不通过重试提交掩盖失败。
- 模型接入成功与脚本化测试通过不代表开放互联网任务的成功率。尚不能声称优于通用 Agent。
- Kimi 的 Anthropic 兼容接口不接受 SDK 原生 PDF `document` 内容块。产品使用 PDF.js 在本机按页提取文字，扫描页转成图片；禁止 SDK Read 直接读取 PDF。每次最多 3 页，每页文字最多 16,000 字符，图像最长边 1,600 像素，识别困难时支持人工补充。
- 开发环境需要 Node 22.13 或更新版本；桌面用户使用应用自带 Electron 运行时，无需安装 Node。
