# ProfilePilot 浏览器连接：隐私说明

更新日期：2026 年 10 月 15 日。发布者：ffffhx，ProfilePilot 项目维护者。

本说明适用于 ProfilePilot 浏览器连接扩展及其与本机 ProfilePilot 浏览器服务的连接。扩展需要配套 CLI 或桌面应用；通过 CLI 使用外部 Agent 时，桌面窗口可以关闭。

## 处理哪些信息、用于什么

- 网页与标签页：任务需要的页面标题、网址、文本、页面结构、选择内容、截图及输入内容，用于理解页面和执行用户请求。
- 浏览历史与下载：按请求查询的浏览记录、下载网址、文件名、状态和任务下载文件，用于查找页面或处理任务结果。
- 调试信息：按任务需要取得的网络、控制台、性能和 frame 信息，用于网页诊断与自动化。网页内容、截图或调试信息可能包含个人信息、登录后内容及其他敏感字段。
- 连接与控制状态：Profile 标识、配对信息、站点偏好、任务标签组、会话标识及控制权，用于连接恢复、区分任务以及用户暂停、停止和接管。

默认完整访问支持用户指定的跨网站任务；可限制站点范围。此扩展连接功能不复制整个 Chrome 用户数据目录或登录数据库，也不会因安装扩展而主动上传完整浏览历史。

## 信息流向

扩展通过 127.0.0.1 上的本机回环连接与 ProfilePilot 浏览器服务通信。扩展不向发布者运营的遥测服务器发送浏览数据，不投放广告，也不出售用户数据。

任务观察结果会返回调用它的桌面应用或外部 Agent。页面内容、截图、附件、输入和调试结果可能由这些调用方发送给用户配置或使用的模型服务，适用相应服务的设置和隐私条款。用户请求的网页操作还可能把信息提交给目标网站。整个使用流程不保证所有数据都留在设备内。

访问项目主页、下载安装包或提交反馈时，GitHub 等承载服务会按其自身隐私规则处理访问信息。桌面应用的其他可选功能不因安装本扩展而自动启用；启用时应另行考虑其接收方和设置。

## 本机保存与删除

扩展私有存储保存配对与站点偏好；会话存储用于标签页选择和任务标签组恢复。本机服务保存连接配置及必要运行状态。任务历史、诊断日志、下载文件和主动保存的截图可能保存在调用方或用户选择的本机目录。

这些数据没有统一的按天自动到期承诺。用户可解除配对、移除扩展，并在对应应用、Agent 或文件目录中删除任务记录和保存的文件。移除扩展不会同时删除桌面应用、CLI、Agent 记录或已经下载的文件。第三方服务自行决定其收到的数据的保存和删除方式。

连接使用配对验证和本机监听，扩展凭据保存在扩展私有存储。请勿将配对码、访问令牌或未经脱敏的记录发到公开反馈中。

## 用户控制与数据用途限制

可选择任务使用的 Profile 和页面，调整站点权限，随时暂停、停止、接管或解除配对。停止任务不会撤销已经提交给网站的操作，也不会删除已发送给第三方服务的信息。

ProfilePilot 对通过 Chrome API 获得的信息的使用和转移遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。相关信息用于提供用户请求的浏览器任务功能，不用于广告投放、出售给数据经纪商或判断信贷资格。
