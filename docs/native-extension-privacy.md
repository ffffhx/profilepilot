# ProfilePilot 浏览器连接：隐私说明

发布准备稿，2026-09-26。正式发布前，发布者应将此说明放在可公开访问的 HTTPS 页面，并在商店填写相同 URL。本仓库文件不代表隐私页已部署或商店已审核。

## 数据与用途

扩展连接当前 Chrome Profile 和本机 ProfilePilot。用户发起任务后，应用及代理工具可读取页面文本和结构、选择内容、标签页标题与网址、截图；按请求查询浏览历史、记录调试信息（包括网络/控制台数据）、操作页面并处理任务下载。这些内容可能含个人信息或登录后可见的敏感字段。默认完整访问用于支持用户的浏览器任务，可限制站点，并随时停止或接管。

扩展通过本机 loopback 通信，不向扩展发布者的遥测服务器发送浏览数据，不投放广告，不销售数据。ProfilePilot 应用可把任务需要的页面内容、截图、附件或调试结果发送给用户配置的模型服务，适用接收服务的隐私条款。外部 Agent 也可通过本机认证工具请求能力。因此不能宣传整个产品“所有数据绝不离开设备”。

## 本机保存与控制

扩展私有存储保存配对、访问偏好与连接恢复状态；应用使用系统安全存储保护凭据。任务记录、下载副本、可选截图可能保存在应用数据目录，保存期限由应用设置决定。连接不会复制整个 Chrome 用户数据目录或登录库。

断开配对撤销本机连接；删除扩展会删除 Chrome 为其管理的存储。任务历史和下载副本属于应用数据，需在应用内管理。停止/接管不会撤销已经提交给网站的操作。Chrome 设置也可调整网站及扩展访问范围。
