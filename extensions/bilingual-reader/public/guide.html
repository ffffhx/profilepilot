双语伴读为网页添加逐段译文，保留原文、链接和代码。配置保存在本机。

安装浏览器扩展

  1. 将插件构建后的 dist 文件夹保留在固定位置。下载 ZIP 的用户先解压。
  2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
  3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 manifest.json 的文件夹。
  4. 在扩展菜单中固定「双语伴读」。安装或更新后，刷新之前打开的网页。

Windows 和 macOS 使用同一份构建产物。此版本面向桌面 Chromium 浏览器；Safari、Firefox 尚未适配。

选择翻译服务

浏览器本地翻译：在设置中选择原文和目标语言，然后点击「测试翻译」。支持此 API 的 Chrome 会按需下载语言包，网页中的「启用」按钮也可触发下载。若当前设备不可用，请切换自定义接口。

自定义 AI 接口：填写兼容 Chat Completions 的服务地址、模型名称和 API Key，点击测试并授权该接口域名，然后保存。允许 HTTPS 服务以及 localhost / 127.0.0.1 上的 HTTP 服务；密钥可留空以连接无需认证的本机服务。

原文语言需手动选择。API 请求会发送待翻译正文、页面标题和术语表；密钥保存在本机扩展存储中，不能视为系统密码保险库。

开始阅读

  • 点击扩展图标 →「翻译此页」，或者按 Alt + T（macOS 为 ⌥ + T）。
  • 译文随滚动出现。网页底部工具条可以查看进度、重试或恢复原文。
  • 选中文字后点击「译」，或使用右键菜单，查看并复制单段翻译。
  • 在扩展菜单为当前站点选择「总是翻译」「手动翻译」或「不翻译」。
  • 修改模型、语言、术语或样式后保存，正在翻译的页面会使用新设置重新开始。

目前支持的范围

适合普通网页文章、技术文档、列表和大多数动态加载内容。不会翻译代码块、输入框、编辑器、导航以及显式标记为不可翻译的内容。

浏览器内部页面、扩展商店、内置 PDF 查看器、跨域 iframe、封闭 Shadow DOM、图片文字和视频字幕不在当前版本范围内。页面有特殊排版或虚拟列表时，可能需要单独适配。

本地缓存最多保留 1,500 条、14 天；可以在设置里清空。配置导出不包含 API Key，导入不会覆盖已有密钥。
