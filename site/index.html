Control surface

浏览器、项目与手机，各有清楚的入口。

桌面负责执行与管理；终端和 Android 移动版让你在其他入口继续处理同一份任务。

A

Agent 任务

描述目标、补充文件，查看执行过程和结果；常用任务可保存为模板或安排定时执行。

B

浏览器环境

管理日常 Chrome 和独立 Profile，查看连接状态，按需同步账号数据与扩展。

C

本地应用

登记开发项目和后台服务，集中查看启动状态、端口与日志，连接支持调试的 Electron 应用。

D

Android 手机

通过 USB 或 Wi-Fi 查看、控制 Android；在手机上向电脑发任务、跟进进度和处理确认。

E

CLI 与外部 Agent

在配套工具中安装 ppilot 和使用指引，从终端对话或让外部 Agent 操作浏览器与手机。

F

逐步高亮引导

框住真实 Tab、按钮和内容，在旁边说明用途。支持上一步、下一步、跳过与随时重新打开。

Download

从官网直接下载 ProfilePilot。

安装包发布在 GitHub Release。支持 macOS、Windows，以及 Android 11 或以上的手机。手机管理电脑任务时，电脑需要保持运行且能从手机访问。

macOS 安装提示

如果提示“已损坏，无法打开”

这是 macOS Gatekeeper 对未签名、未公证应用的拦截。确认安装包来自本页 Release 后，可以在终端执行下面这条命令。

xattr -dr com.apple.quarantine /Applications/ProfilePilot.app
这条命令做什么

删除 ProfilePilot.app 上的 com.apple.quarantine 隔离标记，让 macOS 不再把它当作刚从网络下载且未确认的应用。

为什么需要执行

当前安装包还没有 Apple Developer ID 签名和 notarization 公证。Chrome 下载后会加隔离标记，系统可能把未签名应用显示成“已损坏”。

这是自用测试版的临时处理方式。面向普通用户的正式版本应完成 Apple 签名和公证。
