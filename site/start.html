ProfilePilot任务示例English反馈问题

让已有 Agent 完成第一次网页任务。

适合已经在使用 Claude Code、Codex 等本地 Agent 的人。先从一个只读网页开始，核对结果，再扩展到网站读取或安卓任务。

1. 安装桌面版

从 GitHub Releases选择 Windows x64、macOS Apple Silicon 或 Intel 安装包。先看该版本说明：网站展示的当前源码能力可能尚未进入旧下载包。

2. 连接正在用的 Chrome

在桌面应用「配套工具」中选择日常 Chrome Profile，点击安装并连接。商店入口尚未配置时，按连接页的目录打开 chrome://extensions，开启开发者模式并加载已解压的扩展，再返回连接页完成配对。保留连接页提供的固定目录。

已有连接时直接使用。目标被其他任务占用时先等待；需要独立工作环境时，明确创建并选择另一个 Profile。

3. 安装 CLI 和 Skill

在「配套工具」安装 ProfilePilot CLI 和配套 Agent 使用指引。重开终端，检查安装及连接：

ppilot --version
ppilot browser default --json
ppilot browser status
ppilot browser sites

选择你打算使用的默认 Profile。状态显示被占用或人工接管时，保持原目标和会话。外部控制命令不额外启动模型循环；你的 Agent 仍按自身配置调用模型。

4. 复制给你的 Agent

请使用 ProfilePilot。先读取已安装的 ProfilePilot Skill，检查 CLI、默认 Profile、连接状态及会话占用。使用我指定的网页，只读取标题、正文与原链接，整理三条要点；不要提交表单或发送消息。缺少连接时说明实际缺少的步骤，不擅自换 Profile。完成后结束本次控制会话。

网页：https://github.com/ffffhx/profilepilot

成功标准：目标 Profile 正确，三条要点能在原文核对，原链接可打开，控制会话已经结束。

接下来试三类任务

闲鱼：按规格整理候选
使用 ProfilePilot 的闲鱼读取能力，查找 DDR5 32GB 笔记本内存，预算上限按我随后提供的金额。先核对搜索条件是否生效，再查看候选详情。输出标题、挂牌价、单条或套装、规格证据、原链接；分别列出符合描述、不符合和待确认项。不要联系卖家或购买，不把挂牌价说成成交价。价格历史仅使用实际采样记录。
小红书：整理笔记与已加载评论
使用 ProfilePilot，围绕我给定的关键词搜索小红书。读取最多 5 篇笔记，整理观点、原链接、页面日期和已加载评论中的补充信息。注明实际读取范围；把重复、无结果、登录阻塞与读取失败分开。不要点赞、收藏、评论或私信。
网页与安卓：分别验证一次操作
使用 ProfilePilot，先在我指定的浏览器 Profile 检查本地网页的登录表单，再在已连接的指定安卓设备上检查对应页面。先发现目标和控制状态，分别取得各自会话。只使用我提供的测试账号，不提交真实订单。记录操作、实际结果与阻塞，完成后结束各自会话。

卡住时先检查这些

找不到 ppilot
重新打开终端，再查看配套工具中的安装状态。Windows 与 macOS 都需要当前用户的 PATH 能找到 CLI。
扩展已加载但未连接
核对 Profile 和固定扩展目录；运行 ppilot browser status。按连接页修复，不反复卸载或清空配对。
目标被占用／已接管
等待原任务结束，或由用户明确交还；不要新建会话抢占。
安卓不可控制
运行 ppilot phone list，按设备页检查连接和必要权限。iPhone 不属于这条即装即用路径。
macOS 安装受阻
核对来源、芯片架构及 Release 安装说明。签名、公证状态以下载版本说明为准。

反馈时附系统、App／CLI／扩展版本、目标类型、步骤与错误码。不要附配对码、令牌、未脱敏页面或个人资料。查看扩展隐私说明。

Quick start with your existing agent

  1. Download the correct Windows or macOS build from GitHub Releases and read its release notes.
  2. In Companion Tools, select your everyday Chrome Profile. When no store link is available, load the unpacked extension from the persistent directory shown by the app, then pair it.
  3. Install the ProfilePilot CLI and bundled Skill together. Open a new terminal and run ppilot --version, ppilot browser default --json, and ppilot browser status.
  4. Ask your existing agent to read the Skill, check target ownership, summarize a page you name, include its source link, and complete the control session.

Different agents may use different Profiles or independent apps. Site reads are experimental and their scope varies. YouTube transcripts require existing captions. Page content provided to your agent may be sent to its model provider.

Use ProfilePilot and read its installed Skill first. Check the CLI, saved default Profile, connection and ownership. Read https://github.com/ffffhx/profilepilot and return its title, three source-grounded points and the original URL. Do not submit forms or messages. Explain missing setup without switching Profiles. Complete the control session when finished.
